This dataset consists of resting-state data from 13 stroke patients using a bedside high-density diffuse optical tomography (HD-DOT) imaging system. HD-DOT data are in SNIRF format.

Preprocessed HD-DOT data are in the /derivatives folder in NIFTI format.

This dataset is from the manuscript: Karla M. Bergonzi, Broc A. Burke, Morgan Fogarty, et al. "Disrupted functional connectivity during stroke recovery revealed via bedside optical neuroimaging," Neurophotonics 13(3), 035002 (8 Jul 2026) https://doi.org/10.1117/1.NPh.13.3.035002

A preprint related to this work can be found at: https://doi.org/10.21203/rs.3.rs-107369/v1.
